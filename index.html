Thuật toán Tự động tắt khi không có người

Chu kỳ kiểm tra: T_poll = 10 giây

1. Thu thập dữ liệu đầu vào

  • Trạng thái hiện diện: P_status (True/False)
  • Thời điểm cuối cùng phát hiện người: T_last_seen
  • Thời gian trễ cấu hình: T_delay (phút)
  • Trạng thái máy lạnh: AC_on (True/False)

2. Xử lý trạng thái người dùng


if P_status == True:
    T_last_seen ← null        # Hủy bộ đếm
    (kết thúc vòng lặp)

else:   # P_status == False
    if T_last_seen == null:
        T_last_seen ← T_current
        (lưu vào cơ sở dữ liệu)
    else:
        Δt = T_current - T_last_seen

3. Quyết định điều khiển


if Δt ≥ T_delay AND AC_on == True:
    sendCommand("POWER_OFF")
    T_last_seen ← null        # Reset
else:
    (không làm gì – chưa đủ thời gian hoặc máy đã tắt)
